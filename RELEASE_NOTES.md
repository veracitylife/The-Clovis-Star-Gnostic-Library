# Clovis Star 1.2.0

This release is the current production-shaped Clovis Star site snapshot, including the member area, admin surface, THOTH integration, retrieval and provider services, PayPal/Stripe foundation, operational scripts, tests, and deployment documentation.

The public repository intentionally excludes credentials, environment files, member/session data, databases, logs, backups, QA screenshots, generated archives, and private operational records.

The runtime reads provider credentials from the server-side secret mapping and keeps the public site bundle free of API keys and payment secrets.
