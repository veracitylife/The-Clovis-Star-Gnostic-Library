# THOTH/Hermes source catalog

| Priority | Source class | Use in RAG | Rights/status |
|---|---|---|---|
| 1 | Critical editions of *Corpus Hermeticum* and *Asclepius* | Passage-level primary text | Acquire only licensed or public-domain editions with translator metadata |
| 2 | Egyptian primary texts and museum records concerning Thoth | Ancient Egyptian context | Cite object/text identifiers; do not infer unsupported biography |
| 3 | UCLA Encyclopedia of Egyptology | Scholarly context | Open-access scholarly reference; ingest only permitted text/metadata |
| 4 | Museum collections: Met, British Museum | Object provenance and contextual scholarship | Ingest permitted descriptions and stable identifiers |
| 5 | Cambridge Digital Library, Newton Papers | Early-modern Emerald Tablet reception | Primary manuscript evidence for Newton, not ancient origins |
| 6 | Modern scholarly books/articles | Interpretive context | Catalog metadata and licensed excerpts only |
| 7 | Theosophical/occult/modern esoteric works | Reception history only | Explicitly label as later tradition or pseudohistory where warranted |

Blocked sources are never accessed through CAPTCHA, proxy rotation, browser-agent evasion, or paywall bypass. Add an alternate legal edition or catalog record instead.
