Catalog API

Approved members can create one active token from the member dashboard. Send it as a bearer token with every catalog request.

Authorization: Bearer YOUR_TOKEN

OpenAPI JSON

Endpoints

Catalog

GET /api/v1/catalog

Returns public book summaries, collection data, and current catalog statistics.

Collections

GET /api/v1/collections

Returns the available public collections and their book counts.

Book

GET /api/v1/books/{slug}

Returns one public book with clean paragraphs suitable for display in a partner app.

Example

fetch("https://clovisstar.com/api/v1/catalog", {
  headers: { authorization: "Bearer YOUR_TOKEN" }
})

Private books are never returned through the public API.
