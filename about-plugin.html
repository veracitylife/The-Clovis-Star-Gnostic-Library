Gnostic Bible Super Search

This free WordPress plugin integrates a capable Bible client with a public API. It can also connect to a self-hosted API for complete autonomy.

Download: https://spunwebtechnology.com/gnostic-bible-super-search

Origins and Source

Based on the open-source Bible SuperSearch project (client and API). Spun Web Technology expanded and branded it, added offsite API setup guidance, documentation, and extended collections.

Highlights

  • Search and reference lookup across enabled Bible versions
  • Standalone client or connected to public/self-hosted API
  • Bible downloads and alternate renderings
  • Extended collections of gnostic and historical writings

Public API

The public API is free to use. You can also host your own API and point the plugin to it.
