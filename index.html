    Gnostic Bible Super Search

    Gnostic Bible Super Search is an extended, research-focused fork of the open–source Bible SuperSearch plugin, created by Ryan Thompson of Spun Web Technology.

    Built for researchers, students, and anyone exploring the broader world around the Bible, this plugin adds a rich collection of early Christian writings, gnostic texts, apocrypha, church fathers, historical witnesses, and related works – then connects them to powerful search and comparison tools, right inside WordPress.

    What Does Gnostic Bible Super Search Do?

    At its core, Gnostic Bible Super Search is a text exploration and comparison tool. It takes the solid foundation of the original Bible SuperSearch project and expands it with:

    • Access to a wide range of additional books and documents, both biblical and extra-biblical.
    • Side-by-side comparison views for tracking changes, edits, variants, and parallel passages.
    • Support for both traditional biblical canons and alternative/expanded collections.
    • A free API so you can import all of these books into:
      • the Gnostic Bible Super Search plugin, or
      • the original Bible SuperSearch API and client.

    The goal is simple: give you direct, flexible access to as many relevant sources as possible, so you can see the texts for yourself and draw your own conclusions.

    The Clovis Star Library

    The plugin ships with – and is powered by – the Clovis Star Library, a curated collection of:

    • New Testament writings
    • Apocrypha
    • Gnostic gospels and gnostic treatises
    • Early Church Fathers and heresiologists
    • Historical Roman and Jewish sources that mention early Christians
    • Apocalyptic literature and apocryphal acts
    • Other early Christian and related writings
    • Later, controversial, or fringe works such as the Kolbrin Bible

    These texts are also available in a clean, static HTML format as the Clovis Star Library, which you can browse independently. The plugin makes that same corpus searchable and comparable inside WordPress.

    Key Features

    Extended Text Collections

    Includes canonical New Testament books, apocrypha, gnostic writings, apocalyptic texts, church fathers, and more.

    Side-by-Side Comparison

    Compare passages between different books and traditions, canonical vs. non-canonical writings, and alternate versions and fragments where available.

    Research-Oriented Tools

    Designed to help you trace themes across multiple texts, observe how stories, doctrines, and ideas develop, and explore alternative canons and communities of interpretation.

    Free, Open API

    The underlying API lets you import all available books into this plugin, use the same data with the original Bible SuperSearch API and client, and build your own tools or front ends using the same corpus.

    Flexible Architecture

    Use Gnostic Bible Super Search as a standalone plugin in your WordPress site, together with a public Bible SuperSearch API, or with a self-hosted Bible SuperSearch API for maximum control.

    Included Collections & Example Texts

    The collection is growing, but currently includes (among many others):

    • New Testament Books – Gospels, Acts, Pauline letters, General Epistles, Revelation.
    • Apocrypha & Deuterocanon – Additional books traditionally found in some Christian canons.
    • Gnostic Writings – e.g. Gospel of Thomas, Gospel of Philip, Apocryphon of John, Pistis Sophia, The Tripartite Tractate, The Holy Book of the Great Invisible Spirit, and more.
    • Early Church Fathers & Related Authors – e.g. Ignatius of Antioch, Justin Martyr, Irenaeus of Lyons, Tertullian, Origen, Eusebius of Caesarea, and others.
    • Historical Sources – e.g. Flavius Josephus, Tacitus, Suetonius, Lucian of Samosata, etc.
    • Apocalyptic & Visionary Texts – e.g. Apocalypse of Peter, Apocalypse of Paul, Coptic Apocalypse of Peter, Apocalypse of Thomas.
    • Other Early Christian Writings – Letters, apologies, homilies, acts, and doctrinal fragments.
    • Later / Controversial Works – such as The Kolbrin Bible.

    For a detailed list of included works, see the Table of Contents or the “All Books” view within the library.

    Download & Installation

    Gnostic Bible Super Search (WordPress Plugin)

    You can download the WordPress plugin here:

    Download Gnostic Bible Super Search

    1. Log in to your WordPress admin dashboard.
    2. Go to Plugins → Add New → Upload Plugin.
    3. Upload the ZIP file and click Install Now.
    4. Activate the plugin.
    5. Configure any API or library options as needed.

    Using the API

    Gnostic Bible Super Search exposes a free API that lets developers and researchers query texts and passages programmatically, retrieve books, chapters, and segments across the entire library, and integrate the corpus into other apps, tools, and research workflows.

    You can point the plugin at the public Gnostic Bible Super Search / Bible SuperSearch API endpoint, or at your own self-hosted Bible SuperSearch API instance. Documentation and examples will be provided for common use cases (site search, cross–reference widgets, parallel text views, etc.).

    Project Philosophy

    This project is offered as a research tool, not as an endorsement of any particular theology or tradition. Many of the texts included are disputed, fragmentary, or controversial. Some were preserved by communities labeled “heretical” in antiquity; others come from later esoteric or fringe traditions.

    The aim is:

    • To make the texts accessible.
    • To give you the ability to compare sources and trace ideas across time.
    • To keep the plugin neutral and text–first, letting you do the interpretation.
